Read README.md. Reply with one sentence that includes that marker word. After the sentence, finish.

The marker word is MARKER. It is the only word in the body of README.md. The reply is one sentence. No file is created. No file is edited. No shell command is required. No second pass is required.

The standing task stays the same if another round starts. Read the marker again and reply with one sentence. Stay inside this repository.

README.md is at the repository root. The marker is a single word. The sentence can be short. Finish after that sentence.

This task is the whole prompt. There is no hidden file to open. There is no test to run. There is no patch to write. A one-sentence reply is complete.

Read the marker. Reply once. Finish.
